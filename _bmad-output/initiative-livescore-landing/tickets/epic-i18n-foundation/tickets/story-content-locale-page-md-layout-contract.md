# content/{locale}/{page}.md layout contract

## Description

Establishes content/{locale}/{page}.md (product locale ids, pt-BR for /pt), documents the URL↔content map for later epics, and loads the locale home placeholder body from content/{locale}/home.md.

## Requirements

Verify: content/en/home.md exists and its text appears on /en; content/pt-BR/home.md exists for Portuguese; in-repo mapping note documents URL pt → content pt-BR for epic 2+.
